# Receitas

Uma receita é um ajuste reutilizável que a IA de Vendas sabe aplicar em qualquer site. Formato:

1. **Quando usar** — o sintoma ou a lacuna.
2. **O que verificar** — como confirmar que a lacuna existe (e que não é decisão deliberada do cliente).
3. **Critério de "certo"** — como saber que ficou bom.
4. **Como corrigir** — o padrão, em passos.
5. **Cuidados** — riscos, privacidade, ordem de publicação.
6. **Caso real** — onde já foi aplicada.
